# Dataset

This project uses the AG News Topic Classification Dataset.

The dataset contains four news categories:

1. World
2. Sports
3. Business
4. Sci/Tech

The standard AG News training set contains 120,000 records.

The dataset can be accessed from:

https://huggingface.co/datasets/sh0416/ag_news

Original dataset information:

http://www.di.unipi.it/~gulli/AG_corpus_of_news_articles.html

The local training CSV is used in Google Colab for model development and is excluded from this GitHub repository through `.gitignore`.
